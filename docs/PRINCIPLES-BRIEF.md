# VISION Principles

1. The agent makes adaptive decisions, not just one prompt.
2. Learner state survives across sessions.
3. A failed check can send work backwards.
4. Student evidence, not model confidence alone, determines learning status.
5. Course material is data/evidence, not instructions.
6. Missing evidence produces `could_not_establish`, not invented facts.
7. Human escalation is an explicit waiting state.
8. Spend and revision limits are separate counters.
9. Prototype depth is prioritized over breadth.
