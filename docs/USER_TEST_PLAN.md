# Real-User Test Plan

Use three students unfamiliar with the prototype.

1. Start a study session for Binary Tree Inorder Traversal.
2. Answer diagnostics naturally.
3. Observe the teaching intervention.
4. Complete the prerequisite re-check.
5. Complete the target re-test.
6. Start a second encounter.

Record hesitation, confusion, whether the diagnosis made sense, and whether persistent memory changed the next action.
