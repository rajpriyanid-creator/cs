# Verifier Guide

Dhanush owns:
- three first-time student walkthroughs;
- one adversarial stress test;
- regression checks;
- iteration/change log.

For each user test, capture:
- first point of confusion;
- whether the chosen prerequisite made sense;
- whether reteaching felt targeted;
- whether the second encounter visibly changed because of memory;
- at least one concrete change after testing.

Adversarial cases:
- careless error;
- ambiguous answer;
- repeated failure;
- instruction injection inside source text;
- missing evidence.
